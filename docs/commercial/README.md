## Recommended order

```text
proof of work
→ paid calibration
→ reusable adapter
→ implementation sprint
→ recurring CI / evidence plan
```

Do not skip directly to a large SaaS dashboard before the first repeatable paid integration.

## Ethics and confidentiality

- reuse generalized failure classes and our own method;
- keep each company's private evidence private;
- never sell leaked competitor information;
- never request production credentials in plaintext;
- keep provider guarantee, observed fact, DI inference, and remaining assumption separate;
- present scarcity only when multiple real conversations or engagements exist.
